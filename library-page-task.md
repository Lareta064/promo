# Инструкция по верстке страницы library
# Фаза 1
В корне проекта в папке figma-reference, в папке library-page изучи изображения страницы library на десктоп версии и на мобильной версии. Изображение library-page-desktop.pnp - это общий вид страницы. Шапка уже сверстана. Левая часть с картинками тоже сверстана. Задача - сверстать правый контент, в котором отображается таблица со списком списком статей. На десктоп версии располагается две таблицы рядом. 
Под таблицами элемент - пагинация.
В таблице есть колонки: Порядковый номер, Название, Дата опубликования, Количество слов, Время на прочтение.
На промежуточных экранах, что бы колонки помещались, в первую очередь можно скрывать колонку с количеством слов, во вторую очередь со временем  на прочтение. Далее, на еще меньших экранах, оставить только одну таблицу.
Макет для моб версии изображен на картинке library-page-mobile.pnp 
На картинке mobile-click-single-article показано, как раскрывается информация о статье, по клику на строку таблицы
На десктоп версии клик по названию страницы переводит на страницу статьи. Это будет реализовано в другой задаче.

Код правой части надо добавить в файл src - pages - library.pug  внутри дива .main-right
Для данной задачи не надо создавать компоненты в папке ui
